پنل مادر · پشتیبانی و مدیریت مدارس

با حساب پنل مادر تعیین‌شده توسط مسئول سامانه وارد شوید.

حساب پنل مادر روی سرور نگهداری می‌شود و از حساب مدیر مدرسه جداست. برای تنظیم یا بازیابی، مسئول میزبانی این فرمان را در پوشه برنامه و با همان تنظیمات محیط سرور اجرا کند:

npm run mother:setup

اگر حساب قبلاً ساخته شده و رمز آن فراموش شده است:

npm run mother:setup -- --reset

نام کاربری و رمز جدید در ترمینال دریافت می‌شوند. این کار اطلاعات مدارس و لایسنس‌ها را حذف نمی‌کند. مسیر DATA_DIR یا DB_PATH باید همان مسیر دیتابیس سرور باشد.

پشتیبان‌گیری مدارس

از مدارس روی سرور و پنل مادر نسخه پشتیبان بگیرید. فایل را در جای امن نگه دارید.

اگر مدرسه پرید: همان فایل پشتیبان کامل یا تک‌مدرسه را اینجا بارگذاری کنید تا لایسنس و داده عملیاتی به سرور برگردد.

پنل پیامک مرکزی (ملی‌پیامک)

فقط نام کاربری و رمز API ملی‌پیامک لازم است. آدرس API را خالی بگذارید (خود سامانه پیش‌فرض درست را می‌گذارد). مدیر مدرسه این رمز را نمی‌بیند.
